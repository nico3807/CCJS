Poser les dossiers

Un projet Phaser tient dans deux dossiers. Tout le code source va dans src/, toutes les ressources (images, sons, spritesheets) vont dans src/assets/.

Séparer les deux dès le départ évite de chercher ses fichiers au bout de trois séances.

Sur un projet plus gros, on découpe assets/ en sous-dossiers : images, sons, cartes.
mon-projet/
├── index.html
└── src/
    ├── game.js          le code du jeu
    └── assets/          les ressources
        ├── sky.png
        ├── platform.png
        ├── dude.png
        └── star.png

Brancher Phaser sur la page

Phaser est une librairie JavaScript : le jeu tourne dans le navigateur. La page charge d'abord la librairie, ensuite notre code.

L'ordre compte. Si game.js passe en premier, l'objet Phaser n'existe pas encore.

Dans VS Code, l'extension Live Server sert la page et la recharge à chaque sauvegarde.
<script src="phaser.min.js"></script>
<script src="src/game.js"></script>

Décrire le jeu

Tout part d'un objet config : la taille de la fenêtre, le moteur physique, et les trois fonctions qui composent la scène.

new Phaser.Game(config) lance la machine. À ce stade, l'écran est noir et fait 800 × 600 : c'est normal, rien n'a encore été dessiné.

Passer debug à true affiche les hitbox et les vecteurs de déplacement. Très utile pour comprendre les collisions.
var config = {
  type: Phaser.AUTO,
  width: 800,
  height: 600,
  physics: {
    default: 'arcade',
    arcade: {
      gravity: { y: 300 },
      debug: false
    }
  },
  scene: {
    preload: preload,
    create: create,
    update: update
  }
};

new Phaser.Game(config);

preload() — charger

Appelée une seule fois, au chargement de la scène. On y met les images en mémoire et on donne à chacune une clé.

C'est cette clé, et non le chemin du fichier, qu'on réutilisera partout ensuite.

Un spritesheet demande en plus la taille d'une vignette : frameWidth et frameHeight.
function preload() {

  this.load.image("img_ciel",
                  "src/assets/sky.png");

  this.load.image("img_plateforme",
                  "src/assets/platform.png");

  this.load.spritesheet("img_perso",
                  "src/assets/dude.png",
                  { frameWidth: 32, frameHeight: 48 });
}

create() — construire

Appelée à chaque lancement de la scène. On y monte le décor : fond, plateformes, joueur, animations, collisions.

Les éléments d'une même famille vont dans un groupe. Une seule règle de collision suffit alors pour toutes les plateformes.

staticGroup() pour ce qui ne bouge pas et ignore la gravité. group() pour ce qui tombe et rebondit.
function create() {

  // le fond, ancré par son centre
  this.add.image(400, 300, "img_ciel");

  // les plateformes, regroupées
  groupe_plateformes = this.physics.add.staticGroup();
  groupe_plateformes.create(200, 584, "img_plateforme");
  groupe_plateformes.create(600, 584, "img_plateforme");

  // le joueur
  player = this.physics.add.sprite(100, 450, "img_perso");
  player.setCollideWorldBounds(true);

  // il s'arrête sur les plateformes
  this.physics.add.collider(player, groupe_plateformes);

  clavier = this.input.keyboard.createCursorKeys();
}

update() — la boucle

Appelée en boucle, environ soixante fois par seconde, tant que la scène tourne. Dès qu'elle se termine, elle repart.

C'est là qu'on lit le clavier et qu'on décide de la vitesse du joueur. Le moteur physique s'occupe du reste : gravité, collisions, rebonds.

update() exécutée 0 fois 

function update() {

  if (clavier.right.isDown) {
    player.setVelocityX(160);
  } else if (clavier.left.isDown) {
    player.setVelocityX(-160);
  } else {
    player.setVelocityX(0);
  }
}
